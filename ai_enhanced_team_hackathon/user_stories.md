User Stories

Project: AI Study & Flashcard Generator

Repository: holbertonschool-ai4devs/ai_enhanced_team_hackathon

Core Input & Generation

Paste Study Notes

As a student,

I want to paste raw lecture notes or article text into a clean text area,

So that I can quickly prepare my study material without complex formatting.

Upload Text Documents

As a self-learner,

I want to upload .txt or .md files directly from my device,

So that I don't have to manually copy and paste long documents.

Generate AI Flashcards

As a user,

I want the AI to extract key concepts and generate concise Question/Answer flashcard pairs from my input text,

So that I can save time creating active-recall study materials.

Generate Practice Quiz

As a student preparing for an exam,

I want the AI to generate a 5-question multiple-choice quiz with explanations based on my notes,

So that I can test my comprehension under exam-like conditions.

Study & Interaction

Interactive Flashcard Flip

As a learner,

I want to click or press a key to flip flashcards between the prompt and the answer,

So that I can practice active recall effectively.

Track Card Mastery

As a user reviewing a deck,

I want to mark each flashcard as "Mastered" or "Needs Review",

So that I can focus my remaining study time on difficult concepts.

Instant Quiz Feedback

As a student taking a generated quiz,

I want to see my score immediately upon completion along with the correct answers for missed questions,

So that I can identify and fix my knowledge gaps right away.

Management & Export

Edit Generated Flashcards

As a user,

I want to edit the question or answer text of any AI-generated flashcard,

So that I can refine phrasing or add personal notes.

Save & Revisit Study Decks

As a returning user,

I want my generated study decks to be saved in a history list,

So that I can revisit and review them across multiple study sessions.

Export Study Deck

As a power user,

I want to export my flashcards as a .csv or .md file,

So that I can import them into external tools like Anki or Notion.
