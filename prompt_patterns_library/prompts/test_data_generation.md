**Expected Output**: Valid JSON or SQL seed file containing 5–10 realistic mock data records.

---

### How to Add These Files on GitHub

1. Go to your GitHub repository: `15983-dot/holbertonschool-ai4devs`.
2. Click into the folder **`prompt_patterns_library`**.
3. Click **Add file** $\rightarrow$ **Create new file**.
4. In the file path box, type **`prompts/refactoring.md`** (typing `/` will automatically create the `prompts` folder).
5. Paste the content for `refactoring.md` and commit the file.
6. Repeat the process to create the remaining `.md` files inside the `prompts` directory.
7. Return to your grading portal, select **Repository:** `15983-dot/holbertonschool-ai4devs`, leave **Folder (optional)** blank, and click **Run the correction**.
