Prompt Use Cases

Code Quality

Refactoring

Goal: Improve readability, reduce complexity, and optimize performance without altering behavior.

Input: Source function in [LANGUAGE]

Output: Optimized code + clear explanation of changes

Style & Standards Enforcement

Goal: Enforce project-specific naming conventions, design patterns, and linting rules.

Input: Code block + target style guide rules

Output: Rewritten code compliant with specified standards

Security & Vulnerability Auditing

Goal: Identify security flaws (e.g., SQL injection, XSS, insecure data storage) and patch them.

Input: Code snippet or API handler

Output: Security assessment + hardened code implementation

Debugging & Error Handling

Stack Trace & Error Analysis

Goal: Diagnose the root cause of an application crash or runtime error.

Input: Stack trace + relevant code context

Output: Root cause explanation + recommended fix

Edge Case Identification

Goal: Uncover potential logic gaps, null/undefined failures, or concurrency issues.

Input: Function implementation or business logic logic specification

Output: List of potential edge cases + hardened code version

Legacy Code Explanation

Goal: Deconstruct undocumented or complex legacy code into understandable logic.

Input: Complex or obfuscated code segment

Output: Step-by-step logic breakdown + plain-English summary

Testing & Validation

Unit Test Generation

Goal: Create comprehensive unit tests with mocks for high code coverage.

Input: Target class/function + preferred test framework (e.g., Jest, PyTest, JUnit)

Output: Complete unit test suite covering happy paths and error cases

Integration & E2E Test Scenarios

Goal: Design multi-component testing scenarios for API endpoints or user flows.

Input: Feature specification or API schema

Output: End-to-end test suite or API request collection (e.g., Playwright, Postman)

Test Data Mocking

Goal: Generate realistic mock datasets and fixture structures for testing.

Input: Schema definition (TypeScript interface, SQL table, JSON schema)

Output: Sample mock datasets formatted as JSON, SQL, or language-native objects

Documentation & Knowledge Sharing

API & Function Documentation

Goal: Generate standardized docstrings, README files, or OpenAPI/Swagger specs.

Input: Function signature or API route handler

Output: Standardized docstrings (e.g., JSDoc, Google Docstrings) or Markdown docs

Changelog & Release Notes Generation

Goal: Summarize git commits or diff logs into user-facing release notes.

Input: Commit logs or PR diff summary

Output: Structured changelog categorized by features, fixes, and breaking changes

Architecture Explanation & ADR Generation

Goal: Document system architecture decisions and design trade-offs.

Input: Architectural proposal or codebase structure description

Output: Formatted Architecture Decision Record (ADR) in Markdown
