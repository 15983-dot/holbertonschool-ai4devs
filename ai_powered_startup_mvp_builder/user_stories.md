User Stories - Peer Request & Real-Time Collaboration Hub

User Story 1

As a user, I want to set a lightweight display name when entering the workspace so that my requests and chat messages are clearly attributed without needing a full account registration.

User Story 2

As a user, I want to submit a structured help request with a title, category, priority, and description through a form so that teammates can quickly understand what I need.

User Story 3

As a user, I want to see instant inline validation errors if I leave required form fields empty so that I can fix mistakes before submitting.

User Story 4

As a user, I want to view all submitted requests in a clean, responsive card layout so that I can scan open items easily on both mobile and desktop screens.

User Story 5

As a user, I want to filter requests by status (All, Open, In Progress, Resolved) so that I can focus on tasks that still need attention.

User Story 6

As a teammate or mentor, I want to update a request's status from Open to In Progress or Resolved so that everyone knows the task is being handled or completed.

User Story 7

As a user, I want to switch seamlessly between the Requests board and the Chat channel using tab-based navigation so that I can move between structured tasks and live discussion without reloading the page.

User Story 8

As a user, I want to send and receive real-time messages in the shared chat tab so that I can coordinate follow-up details quickly with peers.

User Story 9

As a user, I want to see an unread badge indicator on the Chat tab when new messages arrive while I am viewing Requests so that I never miss an urgent update.

User Story 10

As a user, I want to receive clear visual toast notifications when my actions succeed or fail so that I have immediate confirmation that my data was saved.
